## Findings (hostile, ordered by damage)

**F1 — "Mainnet is deliberately impossible" is overstated. (HIGH, credibility)**
`validateConfig` only applies the mainnet regex *inside* `if (config.venue === "devnet")`,
and the regex is `/mainnet|api\.mainnet-beta/i` against the URL string. A mainnet endpoint
whose hostname does not contain "mainnet" — any Helius/QuickNode/Triton/Ankr mainnet URL —
passes the check. Separately, `cli.js doctor` calls `devnetHealth(config)` regardless of
venue, so in `paper` mode an arbitrary `HDOG_RPC_URL` is contacted with no validation at all
(read-only calls, so no money at risk — but the claim in README §"Why devnet only" and in
SUBMISSION.md is that config *rejects* a mainnet RPC, and it does not reliably).
A judge reading the security paragraph and then the code finds the gap in 60 seconds.

**F2 — Nothing has ever settled on chain. (HIGH, scoring)**
The brief says *trades*. Fills are simulated; the one genuinely on-chain path
(`devnetExecutor.js`) has never been executed — no signature exists. This is disclosed
honestly in three places, which protects against a DQ, but it caps the ceiling: the only
live Solana artifact in the video is `getSlot`/`getGenesisHash` from `doctor`. Against a
rival that shows one real devnet explorer link, this loses.

**F3 — "implemented and unit-tested" overstates devnetExecutor coverage. (MEDIUM)**
`devnetExecutor.js` is 60.90% line / 60% function. `loadKeypair` and `buildMemo` are tested;
lines 74-92 (`devnetHealth`) and 101-133 (`createDevnetExecutor`, transaction assembly,
`sendAndConfirmTransaction`) are **not covered by any test**. The repo's headline claim is
that the untested part is the part that has also never run. That is the weakest seam in the
whole packet and the exact thing a hostile judge will pull on.

**F4 — The winning tape is written by the same author as the strategy. (MEDIUM)**
`fixtures/runners.sample.json` is synthetic, generated by `scripts/make_fixture.mjs` from an
explicit price path, and the shipped result is +15.5% with a clean take-profit. Disclosed
plainly ("a demonstration of the machinery, not a performance claim") which is the right call,
but a judge can still read it as marking your own homework. There is no evidence in the packet
that the agent was ever run against live data.

**F5 — `SUBMISSION.md` still says the repo URL is a placeholder. (MEDIUM, submission-blocking)**
Line 5: `**Repository:** _(fill in after gh repo create — see RUN.md step 3)_` — while the repo
is already public and RUN.md §3 already names it. The description block is the text that gets
pasted into the platform; shipping it with a "fill in later" line in it is an own goal.

**F6 — Silent demo. (LOW)**
No audio stream at all in any of the three cuts. 55 s of scrolling terminal with no narration
and no captions asks a voter to read fast. Voting is by token holders, not engineers.

**F7 — Three near-identical video files are committed. (LOW)**
`demo.mp4` (2.6 MB) plus `demo_small.mp4` and `demo_x.mp4` which are byte-identical to each
other (835,318 B each, same duration/resolution). 4.3 MB of binaries in the repo, one of them
a pure duplicate, with no note explaining why both small files exist.

**F8 — `minM5Pct` default is 0, documented as "never open into a red 5m candle". (LOW)**
Correct as written, but the gate table in README calls it `no-momentum`/`rolling-over` in prose
while the env name suggests a momentum floor. Cosmetic, but a judge diffing docs against
`config.js` notices the vocabulary drift.

## Concrete fixes (in priority order)

1. **F1** — Move the RPC check out of the `venue === "devnet"` branch so it validates on every
   load, and switch from a hostname regex to an allowlist: accept only
   `api.devnet.solana.com`, `api.testnet.solana.com` and `127.0.0.1`/`localhost`, reject
   everything else with "custom RPC endpoints are refused — this agent is devnet only".
   Then make `doctor` use the same validated value. Add one test:
   `HDOG_RPC_URL=https://mainnet.helius-rpc.com/?api-key=x` must throw, in both venues.
2. **F3** — Add tests for `createDevnetExecutor` and `devnetHealth` against a stubbed
   `@solana/web3.js` (inject the module or a `connection` factory) asserting: transfer
   instruction to the settlement pubkey for `settlementLamports`, memo instruction to
   `MEMO_PROGRAM_ID` with `buildMemo` output, payer is the only signer, returned fill carries
   the signature. Target >90% on that file, then restate the README line as
   "implemented and unit-tested end to end against a stubbed RPC; never executed live."
3. **F5** — Replace the placeholder in `SUBMISSION.md` line 5 with
   `https://github.com/valeemlbb-cell/hackalaunch-hacka-dog-2` and re-read the description
   block top to bottom for any other build-time artefact.
4. **F2** — Highest-leverage single action left: get **one** devnet signature. Retry the
   faucet on a fresh `solana-keygen` key (429 is per-IP-per-day and it is a new day at
   00:00 UTC), or ask the human operator to run RUN.md §2 once. Then paste the explorer link
   into README, SUBMISSION.md and a 6-second tail card on the video. That converts the packet's
   biggest honest weakness into its strongest proof, and it is the difference between
   "simulated" and "it actually touched Solana".
5. **F4** — Commit `runs/live-sample.jsonl`: one real `npm run live` pass against DexScreener,
   even if it takes zero positions, and say so in README ("the agent has been run against live
   market data; here is the journal"). Costs nothing, removes the marking-your-own-homework read.
6. **F6** — Add burned-in captions or a 20-word title card per section (universe → gates →
   risk → result). No voiceover needed. Token holders skim.
7. **F7** — Delete `demo_x.mp4` (identical to `demo_small.mp4`), keep `demo.mp4` +
   `demo_small.mp4`, and add one line to RUN.md §4 saying which to upload where.
8. **F8** — Rename `HDOG_MIN_M5_PCT` to `HDOG_MIN_M5_PCT_FOR_ENTRY` or add a one-line comment
   in `.env.example` tying it to the `rolling-over` gate by name, so the gate table and the
   env table use one vocabulary.
